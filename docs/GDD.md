# 餘燼王國 Realm of Embers — 遊戲設計文件

## 概念

**Minecraft 風格方塊畫面 × 天堂/RO 的打寶與交易 × 家園經營。**
玩家白天在野外打怪掉寶、晚上回家園採礦伐木、打造裝備，把好東西拿到交易所賣給其他玩家。

- 平台：PC（Steam），之後可考慮 Steam Deck
- 視角：2.5D，固定俯角 48° 的透視相機，可旋轉與縮放（RO 式）
- 美術：Minecraft 式方塊世界（16×16 像素材質、方塊人物）
- 所有美術、名稱、怪物皆為原創，不使用天堂/RO/Minecraft 的任何素材或商標

## 核心循環

```
打怪 ──► 掉寶 ──► 自用 / 交易所販售 ──► 金幣
  ▲                                      │
  │                                      ▼
更強的裝備 ◄── 強化 / 插卡 ◄── 家園採集 → 加工 → 製作
```

## 角色成長（RO 式）

- **Base Lv 1–99**：升級給素質點（`floor(Lv/5)+3`），素質越高越貴（`floor((x-1)/10)+2`）
- **Job Lv 1–50**：Job Lv 10 可轉職
- **六素質**：STR（攻擊、負重）AGI（迴避、攻速）VIT（HP、防禦）INT（魔攻、SP）DEX（命中）LUK（爆擊、掉寶）
- **職業**：初心者 → 劍士 / 弓箭手 / 魔法師 / 商人
  - 商人是經營專精：交易稅 −2%、NPC 收購價 +15%、製作成功率 +5%、負重 +1000
- **死亡懲罰**：扣當前等級所需經驗的 1%（不降級）

## 戰鬥

- 點擊怪物自動攻擊（RO），被打自動反擊
- 命中率 = 80% + HIT − FLEE（5%~95%），爆擊必中且無視防禦
- 主動怪（灰狼、骷髏、巫妖王）會追人；追太遠會回血放棄（防拉怪）
- 等級差影響經驗（打高等怪有獎勵，打弱怪大減）

## 強化（天堂式）

- 武器安定值 +6、防具 +4，安定值內 100% 成功
- 超過安定值：50% → 40% → 33% → 25% → …，**失敗裝備蒸發**
- 祝福卷軸：安定值內可能一次 +2/+3
- 保護卷軸：失敗改為 −1（可製作取得，不做成付費道具，避免 P2W）
- 高強化成功時全服公告

## 卡片（RO 式）

每隻怪物都有 0.01% 的卡片。卡片插入有卡槽的裝備後永久鑲嵌，可大幅改變角色能力，是高價交易品。

## 家園系統

| 設施 | 生活技能 | 產出 |
|---|---|---|
| 樹木（橡樹 → 楓樹） | 伐木 | 原木、蘋果、世界樹之枝（史詩） |
| 礦脈（銅 → 鐵 → 秘銀） | 採礦 | 礦石、煤炭、寶石原石、星辰結晶（傳說） |
| 熔爐 | 鍛造 | 礦石 → 金屬錠 |
| 木工台 | 木工 | 原木 → 木板、法杖 |
| 鐵砧 | 鍛造 | 工具、武器、防具（刻上製作者名字） |
| 鍊金台 | 鍊金 | 藥水、強化卷軸、保護卷軸 |

- 需要對應階級的工具（石 → 鐵 → 秘銀）
- 資源點採完會枯竭，一段時間後重生
- 生活技能等級提升：稀有產出機率 +1%/級、製作成功率 +2%/級
- 家園升級解鎖更高階資源點（消耗大量金幣與材料 = 經濟回收點）
